# Capítulo 3 — Forma algébrica dos números complexos

> Como pode existir 'raiz quadrada de menos um'? Se x² + 1 = 0 não tem solução real, que número novo precisamos inventar — e ele é 'de verdade'?
---

## 1. Origem e necessidade dos números complexos

A equação x² + 1 = 0 sem solução real → a necessidade de estender ℝ.

### 1.1 Conceito e linguagem

A definição fica completa com estas relações:
- A cena histórica (Cardano, Ars Magna): raízes de negativos como "ficções úteis".
- Δ < 0 nas equações do 2º grau ganha, enfim, solução.

### 1.2 Procedimento e interpretação

**Equação sem raiz real**

**Resolução:**

$$x^2+4=0$$

$$x^2=-4$$

$$x=\pm2i$$

**Resposta:** ampliar R para C permite resolver a equação.

Girolamo Cardano (1501–1576) é a referência histórica deste tema matemático.
---

## 2. Unidade imaginária: i² = −1

Definição de i com i² = −1.

### 2.1 Conceito e linguagem

Na leitura da notação, dois pontos são decisivos:
- Consequências imediatas (i, −1, −i, 1 no ciclo — apenas apresentar; ciclo completo no Capítulo 4).
- √(−a) = i·√a para a > 0.

### 2.2 Procedimento e interpretação

**Potências iniciais de i**

**Resolução:**

$$i^2=-1$$

$$i^3=-i$$

$$i^4=1$$

**Resposta:** as potências formam um ciclo de quatro valores.

---

## 3. Forma algébrica z = a + bi; parte real e imaginária

Forma z = a + bi com a, b reais.

### 3.1 Conceito e linguagem

O procedimento preserva estas condições:
- Parte real Re(z) = a; parte imaginária Im(z) = b (ambas reais).
- Complexos reais puros (b = 0) e imaginários puros (a = 0).

### 3.2 Procedimento e interpretação

**Partes de z**

**Resolução:**

$$z=-4+7i$$

$$\mathrm{Re}(z)=-4$$

$$\mathrm{Im}(z)=7$$

**Resposta:** a forma a + bi separa parte real e parte imaginária.

---

## 4. Conjunto ℂ; igualdade de números complexos

ℂ = {a + bi : a, b ∈ ℝ}; ℝ ⊂ ℂ estritamente.

### 4.1 Conceito e linguagem

A definição fica completa com estas relações:
- Igualdade: a + bi = c + di ⟺ a = c e b = d.
- Uso da igualdade para determinar partes desconhecidas.

### 4.2 Procedimento e interpretação

**Partes real e imaginária**

**Resolução:**

$$z=3-2i$$

$$\mathrm{Re}(z)=3$$

$$\mathrm{Im}(z)=-2$$

**Resposta:** dois complexos são iguais quando suas partes correspondentes são iguais.
